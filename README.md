# 硬盘整理（DiskOrganizer）

只在当前 Windows 电脑本地运行的硬盘整理工具。扫描本地固定硬盘，把所有格式的文件放进同一张按大小排序的表，并通过 Windows 回收站安全清理。全程离线，不需要登录，不上传任何数据。

## 功能

- **总览**：每块本地固定硬盘的总容量、已用、可用，已识别与未识别构成，文件类型占比，最大文件与最大文件夹 Top 10。
- **全部文件**：所有已扫描文件混排，按大小、修改时间、名称、类型排序，支持硬盘、类型、大小、时间、文件夹筛选和文件名/路径搜索。
- **删除**：只能移到 Windows 回收站，可随时还原；回收站不可用时禁用删除，不提供永久删除。
- **长路径回收区**：Windows 回收站无法接收超过 260 字符的路径，这类文件会移到所在硬盘的软件回收区（`<盘符>\.disk-organizer-trash\`），可在“设置 → 长路径回收区”还原，不会被永久删除。
- **视频压缩**：无需扫描即可添加本地视频，使用 H.265 全核心编码（实测比原先的慢速预设快约 5 倍），提供画质优先、均衡和更小体积三档。压缩时页面顶部显示阶段、总进度、当前文件百分比、编码速度、已用时和剩余时间；编码进程以低于普通优先级运行，前台操作不受影响。保留分辨率、帧率和音轨，另存 MKV，不覆盖或删除原文件；同名输出自动编号，输出更大则不保留，可随时停止。重编码有损且不能保证码率不变；HDR、杜比视界、旋转视频及不支持的轨道/色彩格式暂不处理。
- **文件勾选压缩与打包**：在“全部文件”勾选后可送入视频压缩，或无损打包为 ZIP / TAR.GZ；支持全部筛选结果（打包上限 10000 个文件，视频上限 200 个）。解压后按盘符与原目录排列，同名压缩包自动编号。打包不覆盖或删除原文件，取消会清理本次临时文件；已变化的索引文件需重新扫描后处理。
- **归类整理**：按类型、扩展名和文件名包含条件自定义并保存规则，也可从视频、图片、文档、音乐、压缩包、安装包等常用预设一键添加；先选来源文件夹、生成预览，再手动勾选和确认移动。同盘规则优先（包括机械硬盘），已有同名目标自动编号且绝不覆盖。跨盘必须另行确认，串行复制并校验 SHA-256 后将原件送入 Windows 回收站或长路径回收区；回收不可用时不移动。支持停止，已完成的移动保留；移动后同步文件索引。每次来源上限 10000 个索引文件，系统/软件目录及链接不参与整理。跨盘副本继承目标目录权限，不保证保留全部 NTFS 扩展属性；可恢复原件仍占用原盘空间。
- **本地持久化**：扫描结果保存在本机数据库，关闭软件、重启电脑后无需重新扫描；自动备份最近 3 份，也可手动备份与恢复。在资源管理器等外部删除或移动文件后，切回软件会自动核对索引并立即刷新，无需重新扫描。
- **侧键返回**：所有界面都支持鼠标侧键“后退”——先关闭当前弹窗或详情抽屉，再返回上一个页面；没有历史时回到总览。
- **设置**：扫描范围、排除目录、隐藏/系统文件、数据目录与备份管理。

## 系统要求

- Windows 10/11 64 位
- 单机、单用户，只处理本地固定硬盘（不处理移动硬盘、U 盘、网络盘）
- 安装包包含视频编码工具，无需另装 FFmpeg；安装后完全离线运行
- 压缩采用 CPU 编码并占用全部核心；任务进行时页面上方可看到实时进度；输出盘需至少待处理视频两倍大小加 64 MB 的临时空间，处理结束后会清理临时文件

## 安装与使用

1. 运行 `release/0.2.0/DiskOrganizer-Setup-0.2.0.exe`，按向导安装。
2. 如果电脑上已安装旧版本，安装程序会提示并自动覆盖安装到原目录，之前的扫描结果和设置都会保留，不需要重新扫描。
3. 首次启动后点侧边栏底部“重新扫描”，勾选要扫描的硬盘并确认。
4. 扫描完成后在“总览”“全部文件”中查看和处理文件。
5. 删除只会把文件移到 Windows 回收站；清空回收站后磁盘空间才会释放。

> 安装包未做代码签名，Windows SmartScreen 可能提示“Windows 已保护你的电脑”。选择“更多信息 → 仍要运行”即可。

### 完整安装压缩包

`npm run build:win` 在生成安装程序后，会额外生成 `release/0.2.0/DiskOrganizer-0.2.0-完整安装包.zip`，并自动解压校验、启动一次解压出的程序。压缩包内容：

```
硬盘整理-0.2.0\
├─ 安装说明.txt          # 安装、覆盖升级、免安装运行、数据位置与卸载说明
├─ SHA256SUMS.txt        # 包内每个文件的 SHA-256
├─ 安装程序\DiskOrganizer-Setup-0.2.0.exe
└─ 运行文件\              # 完整运行文件，解压后双击“硬盘整理.exe”即可免安装运行
```

已存在同名压缩包时不会覆盖，需要先移走旧文件再重新生成。

## 数据位置

所有数据只保存在当前 Windows 用户的本机目录：

```
%LOCALAPPDATA%\DiskOrganizer\
├─ data\
│  ├─ index.db          # 索引数据库（SQLite）
│  ├─ settings.json     # 设置
│  └─ backup\           # 自动备份，最多保留最近 3 份
├─ long-trash.json      # 长路径回收区清单（被移动文件的位置和原路径）
└─ logs\                # 运行日志
```

设置页会显示实际数据目录、占用大小和备份列表。

- 备份：设置页点“立即备份”，或清空数据前软件自动备份。
- 恢复：在设置页选择一份备份点“恢复”，软件会自动重启并载入该备份。
- 卸载：卸载程序默认**不删除**数据目录；重新安装后可继续使用原有数据。需要彻底清除时，手动删除 `%LOCALAPPDATA%\DiskOrganizer`。

## 开发

要求 Node.js 22.5+（推荐 24 LTS），因为数据库使用内置 `node:sqlite`。

```bash
npm install
npm run prepare:video # 开发环境一次性下载并校验本地视频工具（需联网）
npm run dev        # 启动开发版
```

常用命令：

```bash
npm run typecheck  # TypeScript 类型检查
npm run lint       # ESLint
npm run test       # Vitest 单元与集成测试
npm run test:e2e   # 构建后运行 Playwright 端到端测试
npm run build      # 类型检查 + 构建
npm run build:win  # 构建并生成 NSIS 安装包到 release/
npm run perf:check # 20 万文件性能检查（按需生成测试数据）
```

开发调试可用的环境变量：

| 变量                            | 作用                                       |
| ------------------------------- | ------------------------------------------ |
| `DISK_ORGANIZER_DATA_DIR`       | 覆盖数据目录                               |
| `DISK_ORGANIZER_SCAN_ROOTS`     | 覆盖可扫描根目录，多个用 `;` 分隔          |
| `DISK_ORGANIZER_FAKE_TRASH_DIR` | 测试用：把删除写入指定目录而不是真实回收站 |

## 已知限制

- 只支持本地固定硬盘；移动硬盘、U 盘、网络盘不在第一版范围内。
- 删除只有“移到回收站”一个出口，不提供永久删除。
- Windows 回收站不支持超过 260 字符的路径，这类文件由软件的“长路径回收区”接管：文件仍在原硬盘上占用空间，可在设置页还原；软件不会自动永久删除它们。
- 长路径回收区所在的 `<盘符>\.disk-organizer-trash\` 会自动排除在扫描范围之外，不会被重新计入索引。
- 未做代码签名，SmartScreen 可能提示；不影响离线运行。
- 扫描以当前用户权限运行，无权限目录会跳过并计入“未识别”。
